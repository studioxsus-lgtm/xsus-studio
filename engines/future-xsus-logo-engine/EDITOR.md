# Phases 16–20: editor foundation
createEditor(initial) accepts version 1.0.0 documents with unique layer IDs. Supports add/remove/replace/reorder, isolated snapshots, bounded in-memory undo/redo, and SVG rendering for polygon, circle, text and structured M/L/Q/C/Z paths. Text is escaped; raw SVG is not accepted. This is a headless editor API, not a browser UI. Existing concept documents require explicit ID assignment and conversion of typography metadata to text layers. No durable history or pointer interactions yet. Run node --test engines/future-xsus-logo-engine/*.test.mjs.
