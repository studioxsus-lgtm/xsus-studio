# XSUS Logo Creative V2

The public gateway keeps its v1 authentication and request envelope. An optional creative object opts in to the new renderer after Future interprets the brief and Hyper approves a plan. Fields are version (2.0.0), count (3, 6, 9 or 12), seed, and optional slot and revision for selective regeneration. Omit creative for the existing brand-kit renderer. A review outcome contains reasons and no generated kit.

The renderer reuses the editor schema, OpenType runtime, symbol catalog, palette helpers and safety checks. Intent extracts supported EN, FR and SQ design instructions. Industry profiles provide defaults for 204 business activities grouped into 34 sectors. The supplemental catalog contains 1,000 symbols. Procedural families, outlined characters, contour union and difference, and fused subjects supply editable paths. Text remains a separate editable layer. The SVG nonzero fill rule preserves transparent counters. The generation metadata records the brief and parameters for regeneration.

The silhouette comparison uses normalized geometry. Quality checks cover geometry bounds, area, serialization and complexity. Contrast is measured against a suggested display surface. Free-form cultural references and visual balance still require designer review. The system makes no trademark determination.

Run npm ci and npm test inside the engine directory. With the configured Future and Hyper integration credentials, npm run test:live checks their independent services. The public UI browser regression uses LOGO_ENGINE_DIR and optional CHROMIUM_PATH with Python Playwright. It exercises the actual renderer and editor with isolated account fixtures.
