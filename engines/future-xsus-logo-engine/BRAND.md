# Phases 21–25
Brand kits contain palettes, typography and three editable SVG concepts. Mockups are flat vector previews on card, screen and avatar surfaces, not photorealistic renders. Orchestrator defines proposed versioned adapter contracts for Future and Hyper cores, validates response correlation and gates generation on explicit approval and review_required=false. Adapters are injected; no live core connection, authentication, network transport, timeout or persistence is implemented. Existing core APIs must be inspected before integration. Tests use local stubs only. Run node --test engines/future-xsus-logo-engine/*.test.mjs.
