# XSUS App V5.2 — i18n contract and dynamic DOM audit

## Changes
- `language-manager.js`: observes newly assigned `data-i18n`, `data-i18n-placeholder`, and `data-i18n-aria-label` attributes in addition to newly inserted DOM elements. This prevents a late-added translation key from remaining untranslated until the next manual language switch.
- `tests/xsus-app/i18n-contract-v5-2.py`: checks HTML ID uniqueness, language selectors, persistence, document language, change event, exclusion of user input/code, script order, and the mutation observer contract.
- `tests/xsus-app/run-v5-2-checks.py`: runs eight static translation/contract checks and Node syntax checks for all JS files.

## Verified
All eight static checks passed. Node syntax passed for 17 JavaScript files. No claim of real-browser or mobile UI verification is made.
