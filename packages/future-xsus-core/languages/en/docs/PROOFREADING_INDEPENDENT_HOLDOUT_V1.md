# English Proofreading Independent Labels V1

This evaluation dataset contains 15 manually authored, fixed expected
outputs and statuses for English proofreading: corrections, unchanged
sentences and review-required cases. Expected outputs are **not**
generated by calling the engine. The evaluator reports exact-match
accuracy, failures, and a SHA-256 dataset fingerprint. A failed gate
does not cause this reporting test suite to fail; inspect the report
and compare with separately approved quality targets.

**Important limitations:** several examples overlap the existing
public proofreading benchmark and the file is checked into the
repository. It is not a secret or demonstrably unseen holdout.
Its results do not establish generalization, broad language accuracy,
or production readiness. For independent validation, create a new
sequestered and separately reviewed dataset outside training inputs.

Run from `packages/future-xsus-core`:
`python3 -m unittest languages.en.tests.test_proofreading_holdout_report_v1 -v`
